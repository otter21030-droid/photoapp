# 프레임핏 (FrameFit) — 안드로이드 웹뷰 앱

> **웹사이트:** [https://otter21030-droid.github.io/newapp/](https://otter21030-droid.github.io/newapp/)  
> 사진/동영상/PDF 비율 맞춤 및 편집 서비스를 위한 네이티브 안드로이드 전체화면 앱입니다.

---

## 🌟 주요 개선 및 탑재 기능

### 1. 설치 호환성 및 서명 키 고정 (설치 오류 해결)
- **고정 디버그 서명 키스토어(`debug.keystore`)** 를 프로젝트에 내장하여, GitHub Actions가 빌드할 때마다 항상 동일한 인증서로 서명되도록 구성했습니다.
- `versionCode = 2` 및 `versionName = "1.0.1"`로 버전 업그레이드 적용.
- `applicationIdSuffix = ".debug"`를 제거하여 패키지명을 `com.framefit.app`으로 단일화하여 파싱 에러 및 충돌을 원천 차단했습니다.
- **[중요 설치 팁]**: 이전에 테스트용으로 폰에 설치하셨던 구버전 앱이 있다면, 서명 인증서 충돌을 방지하기 위해 **기존 앱을 먼저 삭제한 후 새 APK를 설치**해 주세요. 이번 v1.0.1부터는 키스토어가 영구 고정되어 앞으로는 삭제 없이 계속 덮어쓰기 업데이트가 가능합니다!

### 2. 파일 선택 기능 안정성 100% 보장 (사진, 동영상, PDF, ZIP)
- 파일 선택 창 오픈 직전 불필요한 런타임 권한 다이얼로그 호출을 제거하여 시스템 파일 피커와의 충돌을 해소했습니다. (Android 시스템 피커는 샌드박스로 동작하여 런타임 저장소 권한 없이도 안전하게 파일을 가져옵니다.)
- `FileProvider` Authority 불일치 및 예외 발생 가능성을 원천 차단하고, 2단계 Fallback 예외 처리 및 `ValueCallback` 초기화 가드를 추가하여 어떠한 상황에서도 웹뷰의 파일 선택기가 먹통이 되지 않고 즉시 열리도록 보장했습니다.
- 파일 선택 시 **사진(`image/*`)**, **동영상(`video/*`)**, **PDF 문서(`application/pdf`)**, **ZIP 압축 파일**을 모두 선택할 수 있습니다.

### 3. 모바일 화면 최적화 (PC 데스크톱 크기 문제 해결)
- 기존 웹사이트의 `min-width: 1120px` 데스크톱 전용 가로폭 제한을 해제하고, 모바일 세로 화면(360px~480px)에 최적화된 **반응형 모바일 CSS를 동적 주입**합니다.
- 모바일 뷰포트(`<meta name="viewport">`) 자동 보정 및 텍스트/버튼 크기를 모바일 터치 환경에 최적화했습니다.
- 상단 파일 포맷 바는 매끄러운 가로 스크롤로 전환되고, 파일 업로드 영역 및 제어판이 한 손 조작에 맞게 카드형으로 자동 정렬됩니다.

### 4. 저장공간 내 원하는 위치에 다운로드 (Storage Access Framework: SAF)
- 웹사이트에서 사진, 동영상, 구간별 편집본, 일괄 ZIP 압축 파일을 다운로드할 때 **안드로이드 시스템의 파일 저장 위치 선택 창(SAF: 다른 이름으로 저장)**이 열립니다.
- 사용자가 원하는 폴더(다운로드, 내 파일, SD 카드, 특정 폴더 등)를 직접 선택하고 파일 이름을 지정하여 안전하게 저장할 수 있습니다.
- 대용량 동영상 및 ZIP 파일도 안전하게 저장할 수 있도록 청크(Chunk) 스트리밍 저장 메커니즘을 적용했습니다.

## 🚀 GitHub Actions로 새 APK 빌드 및 다운로드 방법

터미널(PowerShell 또는 명령 프롬프트)에서 프로젝트 폴더로 이동 후 아래 명령어를 실행하여 GitHub에 푸시합니다:

```powershell
cd C:\Users\Hss\.gemini\antigravity\scratch\framefit-android

# GitHub로 변경사항 푸시
git push origin main
```

1. 푸시 후 GitHub 저장소 상단의 **[Actions]** 탭으로 이동합니다.
2. 새로 시작된 **Build Android APK** 워크플로우를 확인합니다.
3. 빌드가 완료되면 결과 페이지 하단 **Artifacts**에서 **`FrameFit-APK`** 를 다운로드합니다.
4. **기존에 폰에 설치되어 있던 구버전 앱을 삭제하신 후**, 다운로드한 `FrameFit-debug.apk`를 설치하시면 정상적으로 설치 및 실행됩니다!
